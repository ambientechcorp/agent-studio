1. ข้อมูลที่เราใช้

เมื่อเข้าสู่ระบบด้วยบัญชี Google เราได้รับเพียง อีเมล ที่ Google ยืนยันแล้ว เพื่อตรวจสอบสิทธิ์การใช้งาน (License) และกำหนดเมนูที่แต่ละบัญชีใช้ได้ เราไม่ได้รับรหัสผ่านของคุณ

2. ข้อมูลการทำงานในโปรแกรม

ประวัติแชท การตั้งค่า และ API key ที่คุณกรอก ถูกเก็บไว้ในเบราว์เซอร์ของคุณเอง (localStorage) คำสั่งงาน AI ถูกส่งตรงจากเบราว์เซอร์ไปยังผู้ให้บริการ AI ที่คุณเลือก โดยใช้ API key ของคุณ

3. Gmail / Google Calendar / Google Drive

ใช้เฉพาะเมื่อคุณกดเชื่อมต่อและอนุญาตเอง และใช้เพื่อทำงานที่คุณสั่งเท่านั้น เช่น อ่านหรือร่างอีเมล ดูนัดหมาย บันทึกไฟล์ เราไม่ขาย ไม่แชร์ และไม่นำข้อมูลเหล่านี้ไปใช้โฆษณา การใช้ข้อมูลที่ได้รับจาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

4. การเก็บรักษาและการลบ

ข้อมูลสิทธิ์ (อีเมลและวันหมดอายุ) เก็บไว้ตลอดอายุการใช้งาน หากต้องการให้ลบ ติดต่อตามอีเมลด้านล่าง ข้อมูลในเบราว์เซอร์ลบได้เองโดยล้างข้อมูลเว็บไซต์ และยกเลิกสิทธิ์ Google ได้ที่ myaccount.google.com/permissions
